# wolfSSH ESP32 Bridge SSH Server Project

This is a fork of wolfSSH Server based on the minimally viable wolfSSL [template](../wolfssh_template/README.md)

Entire purpose of this repo is setting up SSH bridge for STM32F429I-DISCI board through ESP32. 

See the original [command line example client](https://github.com/wolfSSL/wolfssh/tree/master/examples/client)

### Prerequisites

It is assumed the [ESP-IDF environment](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/get-started/) has been installed.
